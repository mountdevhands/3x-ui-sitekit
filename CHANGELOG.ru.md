# Изменения

[English](CHANGELOG.md) · Русский

## 0.3.0-rc5 — кандидат в релиз

- Добавлен терминальный мастер с приветствием, выбором языка, нумерованными
  шагами и меню на `whiptail`. По умолчанию выбран английский; `--lang en|ru`
  пропускает экран языка. `--ui auto|dialog|text` позволяет выбрать окна
  либо нумерованные текстовые меню.
- DNS проверяется сразу после ввода домена. Мастер собирает email, способ
  входа в панель, необязательные клиентские IP/CIDR для HTTPS, тему сайта
  и транспорт. По умолчанию SSH, auto и XHTTP. До установки нужно принять
  условия ACME и подтвердить понятную итоговую сводку.
- Мастер, загрузчик и установщик объединены в поставку rc5 с согласованными
  закреплёнными хешами. Используется побайтно прежний проверенный runtime rc4.
- При установке и смене режима панели в приватный файл доступов сохраняется
  QR-код VLESS в обычном UTF-8. Ошибка автоматической генерации оставляет
  рабочие доступы и ссылку с явной отметкой о недоступном QR.
- Добавлен `credentials --refresh-file` для обновления файла доступов
  с сохранением идентификаторов узла и служб. Ошибка QR сохраняет старый файл.
  `credentials --qr` остаётся просмотром без записи.
- Подготовлены английская и русская инструкции установки, входа и обслуживания,
  включая запуск одной командой с проверкой SHA-256.
- Добавлена воспроизводимая упаковка: проверка runtime и исходных архивов
  зависимостей, согласование закреплённых хешей и полный набор файлов релиза.

Публикация выполняется отдельно от слияния исходников. Историческая приёмка
rc4 не подтверждает новую проверку VPS, ACME и перезагрузки для rc5.
Оставшиеся этапы описаны в [подготовке релиза](docs/RELEASING.md).

## 0.3.0-rc4 — 23 ноября 2026

- Добавлен отдельный комплект закреплённой OpenSSL для управляемого nginx.
- Установка проверяет вложенный манифест до изменения хоста. Запуск nginx
  проверяет обе библиотеки, а диагностика сверяет их с картой памяти процесса.
- Добавлен `install.sh` с точным тегом и SHA-256 для двух файлов поставки.
- Установщик и `status` показывают местоположение файла доступов без
  вывода приватного адреса панели.
- Добавлены инструкции обслуживания, CI и отдельный комплект для GitHub Releases.

## 0.3.0-rc3 — 23 ноября 2026

- Новая установка генерирует путь панели из 32 случайных hex-символов без
  текстового префикса. Значение сохраняется на протяжении жизни установки.
- Добавлен выбор `install --panel-access ssh|https`; по умолчанию SSH.
- В режиме HTTPS можно указать повторяемый `--panel-allow IP/CIDR`.
- Добавлена команда `panel-access` для переключения уже готового узла
  с сохранением учётной записи, пути, сайта, базы и сертификата.
- Ограничение IP действует на оба варианта URL панели и её вложенные
  маршруты, сохраняя доступность сайта и VLESS.
- Добавлены локальные проверки валидации, переключения, восстановления
  после ошибки и маршрутизации на настоящем nginx с тестовым backend.
- Подготовлена документация под названием 3x-ui SiteKit.

На момент rc3 комплект зависимостей rc2 не менялся. Полная установка
на чистом VPS ещё не была принята, bootstrap GitHub не был включён.
