# Обновление

[English](UPDATE.md) · Русский

На работающем узле проверьте `status`, сохраните [резервную копию](BACKUP.ru.md)
и получите standalone соответствующей версии с доверенным SHA-256.
Если временный установщик после bootstrap уже удалён, сначала выполните
[получение установщика для обслуживания](PANEL-ACCESS.ru.md#получить-установщик-для-обслуживания):
скачайте закреплённый rc4, сверьте SHA-256 и сохраните его перед выполнением
команд. Для нового QR обновления ниже нужен скрипт версии разработки.

```bash
sudo python3 https-node.py security-check
sudo python3 https-node.py update-nginx --confirm-domain node.example.com
sudo python3 https-node.py status
```

`update-nginx` проверяет кандидаты из подписанных Ubuntu pockets, строит
план только для пакетов из исходного пакета `nginx`, затем проверяет
запущенный процесс и TLS. Если исполняемый файл уже соответствует
политике, команда может завершиться без перезапуска. Приватный checkpoint
содержит план и сведения для диагностики. При сбое сначала изучите его и
состояние dpkg. Транзакции APT требуют отдельного восстановления при сбое.

Панель, Xray, Certbot и закреплённая OpenSSL обновляются отдельным
кандидатом с проверенным сценарием миграции. `install` предназначен для
чистого хоста. Режим доступа панели меняется командой
[`panel-access`](PANEL-ACCESS.ru.md).

## Обновить файл доступов с QR

Это возможность исходников **0.3.0-rc5-dev**; в опубликованной rc4 параметра
ещё нет. Получите [standalone версии разработки](../dist/https-node.py)
из этой ревизии или соберите его из корня исходников: `python3 -B build.py`.
SHA-256 файла `dist/https-node.py`:

```text
1e19523c9185918be41a9338b4d608343a98dabc5e7979a5bfcda13f5ee1796b
```

Сверьте файл с этим хешем перед использованием как `/root/https-node.py`,
затем выполните:

```bash
sudo python3 /root/https-node.py credentials --refresh-file
```

Если файл лежит в другом месте, укажите его фактический путь. Обновляется
только `/root/https-node-access.txt` из сохранённого состояния, с QR-кодом
VLESS в обычном UTF-8. Переустановки и reload нет; путь панели, логин,
пароль, UUID, база, сайт и сертификат не меняются. Выводится только путь
файла. При ошибке генерации QR старый файл остаётся целым. Для просмотра
без записи используйте `credentials --qr`.

Опубликованный тег rc4, его файлы релиза и команда установки сохраняются.
Обновление исходников не означает выпуск нового принятого runtime.
