# Чистая установка

[English](INSTALL.md) · Русский

Нужны Ubuntu 26.04 amd64, системный CPython 3.14, systemd, свободные TCP
80/443 и публичный IPv4 на интерфейсе VPS. Направьте одну DNS A-запись
домена на этот IPv4 и уберите AAAA, если домен ещё настроен на IPv6.
Используйте штатные подписанные Ubuntu pockets `resolute`,
`resolute-updates` и `resolute-security` с дистрибутивным `Signed-By`.
Если образ включает `resolute-backports`, сохраните оригинал файла
источников и уберите только этот pocket перед установкой.

Сохраните отдельно предыдущие резервные копии. Для чистой установки нужен
отдельный хост со свободными портами и без предыдущего Certbot lineage.
Для двух заранее скачанных файлов используйте [команды README](../README.ru.md).

Для установки из GitHub Releases используйте [проверяемую команду в README](../README.ru.md#одна-команда-из-github-releases).

В интерактивном терминале загрузчик может запросить домен, если убрать
`--domain`. Вместо `--email` можно явно выбрать `--acme-no-email`.
`--transport` принимает `xhttp` или `ws`. Поддерживаемые значения
`--site-theme` показывает `https-node.py preview-site --help`.
Загрузчик передаёт локальный проверенный runtime через `--release-archive`.
При ошибке сохраните вывод и проверьте стадию перед новым запросом к ACME.

## Установка с вопросами и ответами

Для установки в интерактивной консоли сервера используйте пошаговый режим.
Сохраните проверенную локальную копию [setup.sh](../setup.sh) из этих исходников
и запустите:

```bash
sudo bash setup.sh --lang ru
```

Для английского языка используйте `--lang en`; без параметра также выбран
английский. Сразу после ввода домена, до скачивания файлов и установки,
скрипт проверит публичный DNS. Единственная A-запись должна совпадать с
публичным IPv4 на интерфейсе этого VPS, а AAAA-записи быть не должно.
Проверяются два публичных DNS-резолвера; частный адрес `docker0` не
принимается за публичный. При несоответствии можно исправить DNS и повторить
проверку, ввести другой домен или отменить установку. Затем установщик
повторит собственную предварительную проверку.

Остальные вопросы — почта для регистрации, способ входа в панель,
необязательный список IP/CIDR для HTTPS, тема сайта и транспорт. Значения
по умолчанию: **SSH**, **auto** и **XHTTP**. Пустая почта требует отдельного
подтверждения регистрации без email. Адреса HTTPS-списка можно разделять
пробелами или запятыми. Перед началом установки нужно принять условия
Let's Encrypt и подтвердить сводку настроек; оба согласия по умолчанию
равны **нет**. EOF или Ctrl-C во время вопросов отменяет запуск.

Чтобы посмотреть выбранную команду без установки:

```bash
bash setup.sh --lang ru --dry-run
```

При `--dry-run` выполняются проверки DNS без изменения системы, но файлы
релиза не скачиваются, пакеты не устанавливаются. Root для этого режима
не нужен. Вопросы требуют интерактивного терминала; список параметров
показывает `--help`.

Придумывать пароль панели, UUID VLESS или случайный путь не требуется:
установщик генерирует и сохраняет их сам. Фактические доступы будут
в `/root/https-node-access.txt`.

`setup.sh` пока является добавлением в исходниках версии разработки.
Он скачивает и проверяет неизменённый **bootstrap rc4**, а тот проверяет
установщик и runtime rc4. Поэтому пошаговый режим устанавливает
опубликованную rc4; QR в файле и `--refresh-file` по-прежнему требуют
отдельного установщика версии разработки. Опубликованной ссылки на
release-файл `setup.sh` здесь пока нет.

Для автоматизации и запуска без интерактивного терминала используйте
[закреплённую команду rc4](../README.ru.md#одна-команда-из-github-releases)
с явными аргументами. Режим вопросов и ответов требует интерактивного терминала.

## Выбор доступа к панели

По умолчанию используется `--panel-access ssh`, то есть SSH-туннель.
Для обычного HTTPS-входа уже при установке добавьте:

```text
--panel-access https
```

Для ограничения только своим внешним IP также добавьте необязательный
повторяемый параметр:

```text
--panel-allow 198.51.100.24/32
```

Замените учебный адрес своим публичным IP. Без списка HTTPS разрешает
любые IP с обычной авторизацией панели. Сайт и VLESS не получают эти
ограничения. Режим можно позже изменить командой
[`panel-access`](PANEL-ACCESS.ru.md), без новой установки и нового сертификата.

После успеха прочитайте `/root/https-node-access.txt` как root и откройте
правильную ссылку по [инструкции доступа](PANEL-ACCESS.ru.md). Сохраните
проверенный standalone как `/root/https-node.py` для обслуживания:
bootstrap удаляет свою временную копию. При отсутствии файла используйте
[закреплённую загрузку с проверкой SHA-256](PANEL-ACCESS.ru.md#получить-установщик-для-обслуживания).
Команды установки в README получают опубликованную rc4; новые возможности
QR из текущих исходников автоматически в этот релиз не добавляются.
