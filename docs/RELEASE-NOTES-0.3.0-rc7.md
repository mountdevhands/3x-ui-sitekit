# 3x-ui SiteKit 0.3.0-rc7

The English and Russian terminal wizard can be completed with typing,
arrows and Enter. Next, Yes and Install are the default actions. Text
confirmations use `[Y/n]` and require a successful read before accepting Enter.

The last screen shows the Let’s Encrypt Subscriber Agreement together with the
settings and any planned change to `resolute-backports`. Install accepts the
agreement and starts the verified bootstrap. Cancellation and preview leave APT
untouched. The wizard supports terminals as small as 72×22.

RC7 includes RC6's APT preflight and opt-in backports handling with the same
approved dependency runtime.

See the release description for the checks performed on this candidate.
