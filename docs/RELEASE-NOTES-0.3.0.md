# 3x-ui SiteKit 0.3.0

The stable release installs SiteKit on a clean Ubuntu 26.04 amd64 server.
The English and Russian wizard supports typing, arrows and Enter in a
terminal as small as 72×22. Install accepts the Let’s Encrypt Subscriber
Agreement and starts the verified bootstrap. The final review shows any
planned change to the Ubuntu backports pocket.

APT trust is checked before the installer writes its state or changes any
service. The optional `--disable-apt-backports` action preserves original
sources, disables only `resolute-backports` and repeats trust validation.
Cancellation and preview leave the system unchanged.

The release includes the same digest-approved runtime as RC4 through RC7.
The access file contains panel instructions and the VLESS link and QR.
See the published release description for the actual acceptance results.
