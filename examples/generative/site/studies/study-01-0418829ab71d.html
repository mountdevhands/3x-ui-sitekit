Nested frames · 10 steps

10 rectangular outlines are inset by 16 units per step, using a 5-unit stroke.

What is in this study

Constructionnested frames
SVG dimensions960 × 600
Geometric primitives10
Colours#1A430F, #3E9E24, #7CDB61, #D5F4CD

Circles are placed on a regular grid, bars share a baseline, and nested frames use progressively inset rectangles. The parameter JSON records every primitive so changes can be compared coordinate by coordinate.

The actual parameters

{
  "frames": 10,
  "inset_step": 16,
  "stroke_width": 5
}

The JSON download also records every geometric primitive and the SHA-256 of the SVG file.

Make a variation

Open the SVG in a vector editor to move, resize, or recolour its circles, bars, or frames. The JSON lists each primitive's coordinates and colours, providing a reference when making a related variation.

Keep the SVG and CSS in the same directory when using the background-image rule. The CSS also exports the colours as custom properties.
