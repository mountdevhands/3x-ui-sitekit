Five sRGB colours from explicit HSL steps. The strongest measured pair is #40270D / #F7E6D4 at 11.38:1.

Colours#40270D, #88531B, #D5822A, #E6B47F, #F7E6D4

HSL values are converted to eight-bit sRGB colours. Relative luminance and contrast are calculated from those final hex values using the WCAG sRGB formula. A ratio describes a colour pair; it does not certify the accessibility of a whole design.

Ratios use the exact exported sRGB hex values. They describe these pairs, not the accessibility of an entire interface.

The calculations follow the W3C definition of sRGB relative luminance; the contrast ratio is (lighter luminance + 0.05) / (darker luminance + 0.05).

Make a variation

Copy the supplied --study-color-1 through --study-color-5 CSS variables into a stylesheet and assign them to text, backgrounds, or borders. If you change a hex value, calculate its contrast again before choosing a text and background pair.

Keep the SVG and CSS in the same directory when using the background-image rule. The CSS also exports the colours as custom properties.
