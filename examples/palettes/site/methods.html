How the materials are made

From parameters to a usable file

HSL values are converted to eight-bit sRGB colours. Relative luminance and contrast are calculated from those final hex values using the WCAG sRGB formula. A ratio describes a colour pair; it does not certify the accessibility of a whole design.

The calculations follow the W3C definition of sRGB relative luminance; the contrast ratio is (lighter luminance + 0.05) / (darker luminance + 0.05).

One source for image and description

Each study begins with a bounded set of parameters. Those values produce its SVG, its downloadable JSON, and the measurements stated on its page. Compare the image with its numbers to see how individual choices affect the composition.

Three useful formats

SVG contains editable vector geometry. CSS provides colour variables and a local background-image rule. JSON preserves the parameters, primitives and SVG checksum. Download the SVG and CSS into the same directory, then include the stylesheet in your project.

Make a variation

Copy the supplied --study-color-1 through --study-color-5 CSS variables into a stylesheet and assign them to text, backgrounds, or borders. If you change a hex value, calculate its contrast again before choosing a text and background pair.
