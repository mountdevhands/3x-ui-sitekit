About the collection

Repeat Studies

Each item is a real repeating tile. Its large preview is drawn by repeating the same SVG geometry that is available for download, so the preview and the usable material stay connected.

Explore, compare, and adapt

The collection contains 3 original parameter-based studies. Each page pairs the finished image with its dimensions, construction data, and source files. Open two studies to compare their proportions or colour choices, then download a starting point for your own variation.

Take a study into your project

Keep the SVG and CSS in the same directory and apply the study-pattern class to an element with a defined size. Edit fill and stroke values in the SVG to change its colours. When changing tile geometry, preserve the connections at opposite edges to keep the repeat continuous.
