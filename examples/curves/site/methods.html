How the materials are made

From parameters to a usable file

Each path begins at P0 and ends at P3; P1 and P2 are its control points. Mirrored pairs reflect those points across the vertical centreline. Bundles vary the control points while retaining a shared start and end. Moving an inner control point reshapes the curve while its endpoints keep their positions.

One source for image and description

Each study begins with a bounded set of parameters. Those values produce its SVG, its downloadable JSON, and the measurements stated on its page. Compare the image with its numbers to see how individual choices affect the composition.

Three useful formats

SVG contains editable vector geometry. CSS provides colour variables and a local background-image rule. JSON preserves the parameters, primitives and SVG checksum. Download the SVG and CSS into the same directory, then include the stylesheet in your project.

Make a variation

Edit the two inner coordinate pairs after the SVG path's C command to move its control points. The JSON records all four points in order, so you can compare the curve before and after an edit. Use the matching CSS to place the resulting SVG as a background.
