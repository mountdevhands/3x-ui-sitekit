About the collection

Paths and Handles

A curve is presented together with the four points that define it. The collection uses cubic Bezier paths so that each drawing can be inspected, edited, and reproduced from its parameter file.

Explore, compare, and adapt

The collection contains 4 original parameter-based studies. Each page pairs the finished image with its dimensions, construction data, and source files. Open two studies to compare their proportions or colour choices, then download a starting point for your own variation.

Take a study into your project

Edit the two inner coordinate pairs after the SVG path's C command to move its control points. The JSON records all four points in order, so you can compare the curve before and after an edit. Use the matching CSS to place the resulting SVG as a background.
