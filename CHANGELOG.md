# Изменения

## 0.3.0-rc4 — 23 ноября 2026

- Добавлен отдельный комплект закреплённой OpenSSL для управляемого nginx.
- Установка проверяет вложенный манифест до изменения хоста. Запуск nginx
  проверяет обе библиотеки, а диагностика сверяет их с картой памяти процесса.
- Добавлен `install.sh` с точным тегом и SHA-256 для двух файлов поставки.
- Установщик и `status` показывают местоположение файла доступов без
  вывода приватного адреса панели.
- Добавлены инструкции обслуживания, CI и отдельный комплект для GitHub Releases.

## 0.3.0-rc3 — 23 ноября 2026

- Новая установка генерирует путь панели из 32 случайных hex-символов без
  текстового префикса. Значение сохраняется на протяжении жизни установки.
- Добавлен выбор `install --panel-access ssh|https`; по умолчанию SSH.
- В режиме HTTPS можно указать повторяемый `--panel-allow IP/CIDR`.
- Добавлена команда `panel-access` для переключения уже готового узла
  с сохранением учётной записи, пути, сайта, базы и сертификата.
- Ограничение IP действует на оба варианта URL панели и её вложенные
  маршруты, сохраняя доступность сайта и VLESS.
- Добавлены локальные проверки валидации, переключения, восстановления
  после ошибки и маршрутизации на настоящем nginx с тестовым backend.
- Подготовлена документация под названием 3x-ui SiteKit.

Комплект зависимостей rc2 не изменён. Кандидат не прошёл полную установку
на чистом VPS; установка одной командой из GitHub пока не включена.
